# Digital Humanities Data Parser

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![SQLite](https://img.shields.io/badge/SQLite-003B57?style=for-the-badge&logo=sqlite&logoColor=white)
![XML](https://img.shields.io/badge/Format-XML%2FTEI-orange?style=for-the-badge)

Data processing and extraction pipeline designed for historical, manuscript, and archaeological text datasets, structured into relational database schemas.

---

## 🚀 Features

* **TEI/XML Parsing:** Extracts elements and metadata from XML corpora.
* **Text Normalization:** Cleans legacy characters and structures json/csv outputs.
* **Database Integration:** Exports structured text tables into SQLite.
